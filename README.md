# Aeroplane Tracker

Консольное приложение на Python для отслеживания самолётов в воздушном пространстве выбранной страны.

## Запуск проекта
1. Установите зависимости: pip install -r requirements.txt
2. Запустите программу: python main.py
3. Запустите тесты: pytest --cov=src --cov-report=html
4. pytest --cov=src --cov-report=term-missing
